# Product Requirements

## MVP Goal

Provide a local desktop notes experience where masked fragments can be embedded in note text and revealed only after explicit user action.

## In Scope

- plain-text notes
- marker-based masked fragment references
- local storage
- fragment-only encryption
- local validation and manual testability

## Out Of Scope

- whole-note encryption
- accounts
- sync
- cloud
- AI
- collaboration
- mobile
- images
- rich text
