# Cryptonote Project Bootstrap - Repository Structure Plan

## Overview

Create the foundational repository structure for a Tauri + React + TypeScript + SQLite desktop notes application with masked fragment encryption.

## Files to Create

### Core Documentation (root level)

1. **AGENTS.md** - Agent behavior configuration
   - Define agent permissions and workflows
   - Reference Kilo documentation

2. **CONSTITUTION.md** - Project principles
   - No accounts, sync, AI, cloud, rich text, mobile, images, or collaboration
   - Security-first approach to masked fragments

3. **package.json** - Root package.json
   - pnpm workspaces configuration
   - Basic project metadata

4. **pnpm-workspace.yaml** - Workspace definition
   - Define packages/app and packages/core

5. **tsconfig.base.json** - Shared TypeScript config
   - Base compiler options for all packages

### Documentation Files

6. **docs/product/requirements.md** - Product requirements
   - MVP features (masked fragments, no encryption of whole notes)
   - User stories and acceptance criteria

7. **docs/architecture/initial-design.md** - Architecture design
   - Tauri + React + SQLite architecture
   - Marker-based note content approach

8. **docs/decisions/0001-monorepo-stack.md** - ADR
   - Why Tauri + React + TypeScript + SQLite
   - Rationale for monorepo

9. **docs/agent-workflows/kilo-code.md** - Agent workflow
   - How Kilo agents should work in this repo

### Placeholder Package Files

10. **packages/app/** - Tauri + React placeholder
11. **packages/core/** - Shared logic placeholder

### Updates

12. Update existing **README.md** with Cryptonote description
13. Update **.gitignore** for Node.js and Tauri
